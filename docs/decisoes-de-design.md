## Regras de base (briefing do Carlos)
- Só a paleta existente: `#11310C` (tinta), `#C4C240` (destaque), `#F8F9F3`/`#FAFBF6` (fundos),
  `#E13513` (negativo), `#047857` (positivo). Variações apenas por transparência.
- Vermelho/verde só para variação boa ou ruim (IBCS). Nunca decorativo.
- Projeção tracejada, realizado sólido.
- Um número protagonista por bloco, sempre com contexto (▲▼ com sinal e %, comparação, média).
- Todo total abre as linhas que o formam (clique → painel lateral com os lançamentos).
- Números: alinhados à direita, algarismos tabulares, formato brasileiro.
- Sem: grade de cartões iguais com ícone, degradê/sombra/brilho, emoji, pizza, frase de efeito.
